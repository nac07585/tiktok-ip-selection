## 一、TikTok 卡的是 IP 类型，带宽早就过剩了

TikTok 直播推流的码率在 3–6Mbps，1080P 留点余量 20Mbps 上行就够。WePC 最低配给到 200Mbps 带宽、1.5TB 月流量，单直播间连零头都用不完，花时间比带宽没有意义。

真正决定推流稳不稳的是 IP 属性。普通 VPS 拿的是机房 IP，Scamalytics、ipinfo 这类 IP 库会直接标成“数据中心/代理”，平台的识别系统扫到这类属性，降画质、限推流是常见结果。

三个词经常被混用，区别其实很明确：

- **原生 IP**：IP 归属地和服务器所在地一致，没经过转发或伪装
- **住宅 IP**：来自住宅宽带运营商的 IP，IP 库里显示为家庭用户
- **双 ISP IP**：一台机器同时带两个运营商的认证属性，检测工具里呈现家庭宽带特征，可信度最高

三者叠在一起就是“双 ISP 住宅原生 IP”，也是目前 TikTok 直播里最难拿的一类资源。WePC 在美国 9929 系列的产品页顶部直接标了“全场双 ISP IP，TK 神器”，五款里有四款在参数栏单独写了双 ISP。

多账号运营还要算一笔账。TikTok 的风控按“一账号一 IP 一设备”做关联，同一台机器 IP 上挂多个号，很容易被一起处理。机器数量要按账号数来买，这笔钱得提前进预算。

## 六、几个高频问题

**200Mbps 带宽能开几个直播间？**
单路 1080P 推流 3–6Mbps，带宽层面一台机器能带十几路。实际瓶颈在 CPU 和内存，512MB 内存跑一路 OBS 已经比较紧，多开要么上 4 核 6GB 那款，要么按号分机器。

**一台机器能挂多个 TikTok 号吗？**
技术上能，风控上不建议。同 IP 多号容易被关联，一账号一 IP 一设备是更安全的做法，多出来的机器钱省不得。

**机房 IP 就不能直播了吗？**
能开播，但被限流、画质被压到 480P 的概率更高。短期测试可以用，长期做的号不建议。

**WePC 有英国、日本节点吗？**
官网机房覆盖亚洲、美洲、欧洲多个地区，本文能确认当前在售的是美国洛杉矶系列、悉尼和新西兰。英国、日本、新加坡的具体型号和价格，下单前在产品页确认。
